# Как обновлять сайт на Vercel

## Простой способ обновления

### 1. Внесите изменения в код
Отредактируйте файлы в папке `src/` (не в `dist/`!)

### 2. Соберите проект локально (опционально, для проверки)
```bash
cd /Users/romandikarev/Desktop/SelfPage_FinanceSpec
npm run build
```

### 3. Загрузите изменения в GitHub

**Вариант А: Через GitHub Desktop (рекомендуется)**
1. Откройте GitHub Desktop
2. Выберите репозиторий `dikromanfinance`
3. Внесите изменения в файлы
4. В GitHub Desktop увидите изменения
5. Напишите сообщение коммита (например: "Изменил тему по умолчанию на темную")
6. Нажмите "Commit to main"
7. Нажмите "Push origin"

**Вариант Б: Через терминал**
```bash
cd /Users/romandikarev/Desktop/dikromanfinance
# Внесите изменения в файлы
git add .
git commit -m "Описание изменений"
git push
```

### 4. Vercel автоматически задеплоит обновления!

После `git push` Vercel:
- Автоматически обнаружит изменения
- Соберет проект (`npm run build`)
- Задеплоит новую версию
- Обычно это занимает 1-2 минуты

### 5. Проверьте результат
- Зайдите на ваш сайт на Vercel
- Или откройте Vercel Dashboard → Deployments, чтобы увидеть статус

## Важные моменты:

✅ **Всегда редактируйте файлы в `src/`**, не в `dist/`  
✅ **После изменений делайте `git push`** - Vercel сделает всё остальное  
✅ **Проверяйте статус деплоя** в Vercel Dashboard  
✅ **История версий** сохраняется в Vercel - можно откатиться к предыдущей версии

## Если что-то пошло не так:

1. Проверьте логи деплоя в Vercel Dashboard
2. Убедитесь, что все файлы закоммичены и запушены
3. Проверьте, что `vercel.json` настроен правильно
4. Можно откатиться к предыдущей версии в Vercel Dashboard
