# Инструкция по загрузке сайта на REG.RU

## Что нужно загрузить

Все файлы из папки `dist/` нужно загрузить на хостинг.

## Способ 1: Через файловый менеджер (самый простой)

1. Зайдите в панель управления REG.RU
2. Найдите раздел "Файловый менеджер" или "Файлы"
3. Откройте папку `public_html` или `www` (или `dikarevfinance.ru` - зависит от настроек хостинга)
4. Загрузите ВСЕ файлы и папки из папки `dist/`:
   - `index.html` (должен быть в корне)
   - папку `assets/`
   - папку `css/`
   - папку `js/`

**Важно:** Структура папок должна сохраниться!

## Способ 2: Через FTP

### Данные для подключения (найдите их в панели REG.RU):
- **FTP-хост:** обычно `ftp.dikarevfinance.ru` или `ftp.reg.ru`
- **Логин:** ваш логин FTP (обычно такой же как логин панели)
- **Пароль:** ваш пароль FTP
- **Порт:** 21 (обычно)

### Инструкция:
1. Установите FTP-клиент (FileZilla - бесплатный): https://filezilla-project.org/
2. Подключитесь к FTP используя данные выше
3. Перейдите в папку `public_html` или `www`
4. Загрузите все файлы из папки `dist/`

## Способ 3: Через терминал (Mac/Linux)

Если у вас есть SSH доступ:

```bash
cd /Users/romandikarev/Desktop/SelfPage_FinanceSpec
npm run build
scp -r dist/* ваш_логин@ftp.dikarevfinance.ru:/public_html/
```

## После загрузки

1. Откройте в браузере: http://dikarevfinance.ru
2. Если сайт не отображается, проверьте:
   - Правильно ли загружен файл `index.html` в корневую папку
   - Правильно ли сохранена структура папок
   - Подождите 5-10 минут (DNS может обновляться)

## Обновление сайта

Каждый раз, когда вы вносите изменения:

1. Соберите проект: `npm run build`
2. Загрузите обновленные файлы из папки `dist/` на хостинг
3. Готово!

## Структура файлов на хостинге должна быть:

```
public_html/ (или www/)
├── index.html
├── assets/
│   ├── img/
│   │   └── photo.jpg
│   └── lang/
│       ├── en.json
│       └── ru.json
├── css/
│   ├── main.css
│   ├── reset.css
│   ├── utils.css
│   ├── variables.css
│   └── components/
│       ├── buttons.css
│       ├── header.css
│       └── pills.css
└── js/
    ├── main.js
    └── modules/
        ├── language.js
        └── scroll-anim.js
```
